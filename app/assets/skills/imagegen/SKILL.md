description: Генерация иллюстраций новостей внутри приложения TV GPT.
---
Пользователь заказывает обложки, а Android-приложение выполняет генерацию в фоне через свой подписочный транспорт. Desktop, Python CLI, файловая система компьютера и отдельный API-ключ для этого навыка не используются. Этот навык содержит правила работы, а не обещание доступности сервиса.

Для автоматического дайджеста используй digest_refresh. Для новой обложки существующей новости прочти digest_read, выбери реальный article_id и вызови digest_cover_generate с новым operation_id UUID. Сохрани исходные заголовки, факты и источники; промпт описывает только иллюстрацию. Если пользователь явно заказал повторную попытку, это новое поручение. Никогда не повторяй неизвестный сетевой исход автоматически под новым ID.

Промпт: горизонтальная редакционная иллюстрация, конкретный сюжет новости, подходящая композиция для ТВ, без надписей, выдуманных документальных сцен и ложного подтверждения события. Сгенерированная картинка отмечается «Иллюстрация ИИ». Фотография источника остаётся запасным изображением; её наличие не доказывает успех генерации.

queued/running означает только очередь/обработку. Читай digest_job_read по job_id. Подтверждай готовую генерацию только при ready; при failed/unconfirmed скажи кратко фактический результат. Фотографии сайта, выпуск и заставка продолжают работать. Не обещай, что подключение навыка само открыло доступ к генератору. Не переключайся на платный API или другую службу без явного выбора пользователя.
