---
name: app-search
description: Поиск контента внутри открытого приложения телевизора.
---
Перед работой с приложением проверь доступный встроенный навык: сейчас есть youtube для com.google.android.youtube.tv. Загрузи его через load_app_skill(name="youtube") один раз в текущем разговоре перед поиском или навигацией в YouTube; затем используй уже полученные инструкции. Для остальных приложений продолжай общий сценарий без выдуманных специальных навыков. Навык не заменяет текущий экран и проверку результата.
Когда пользователь хочет посмотреть видео, фильм, сериал или послушать музыку, сначала получи list_apps и выбери подходящее установленное приложение по смыслу запроса и предпочтениям. Это общее правило для любых сервисов (YouTube, Apple TV, Prime Video и других), а не жёсткая привязка к одному. Если подходящего приложения нет, ищи в вебе. Справочные вопросы «вышло ли», «когда выйдет», о погоде и фактах можно сразу искать в вебе.
При продолжении или исправлении поиска сохраняй исходную цель и ограничения (качество 4K, тип видео и т.п.), не сужай запрос до одного неоднозначного слова. Не переспрашивай уже понятную цель и не отказывайся искать из-за одной неудачной попытки.
Сначала найди поиск в нужном приложении. Предпочитай доступный элемент «Поиск», Search или значок лупы; при пустом дереве выясни расположение по снимку и открой поиск кнопками пульта. Не подменяй поиск в приложении общим поиском телевизора без просьбы пользователя.
Когда текстовое поле активно, передай всю фразу через type_text. Русский текст вводится напрямую через редактор Android, без выбора букв стрелками. Не набирай поисковый запрос побуквенно пультом, если type_text доступен. При повторном поиске очисти или выдели прежний запрос; IME-ввод вставляет текст в текущую позицию курсора.
Если search_app не нашёл поле или редактор не принял прямой ввод, это ограничение автоматического способа, а не окончательный отказ. Сам осмотри свежий экран через read_screen и, если дерево пустое, screenshot. Найди вход в поиск в меню приложения и открой его доступными кнопками пульта; попробуй подходящий другой способ, сохраняя исходный запрос. Не отправляй текст в произвольное поле и не повторяй неработающий ввод вслепую. Уточняй у пользователя только действительно неоднозначную цель или недоступное тебе действие, например вход в аккаунт. Если доступные способы исчерпаны, коротко объясни препятствие. После ввода/отправки проверь экран или результат. Принятая команда ввода сама по себе не доказывает, что появились результаты.

Используй общую операцию search_app для любого приложения: исполнитель сначала пробует стандартный поиск Android, затем ищет семантическое поле/кнопку поиска и передаёт запрос напрямую. Для YouTube при недоступном редакторе исполнитель передаёт запрос целиком через поддерживаемую приложением ссылку поиска. Этот путь проверен на телевизоре с русским запросом. YouTube/Cobalt может отдавать только TYPE_NULL InputConnection: ответ commitText=true там не доказывает ввод. Для других приложений search_app пробует системный ACTION_SEARCH; если приложение его не поддерживает, найди его собственное поле и используй type_text. Отсутствующий редактор не обходи побуквенным вводом без объяснения пользователю.

Не озвучивай пользователю технические способы поиска, проверки и промежуточные шаги. Телевизор — место отдыха. Перед поручением допустимо одно краткое естественное подтверждение, затем выполняй поиск без повторной озвучки шагов; при неудаче сообщи коротко и понятно. Технические объяснения давай только по явному вопросу.

Если пользователь говорит «в этом приложении», передай name=current: исполнитель определит текущее приложение сам. Не требуй от пользователя название или технические сведения о приложении.

После search_app оцени приложенное наблюдение. app_visible доказывает только открытое приложение, не выдачу. Подтверди нужный запрос и результаты по дереву, при пустом дереве — по свежему изображению. Если видна загрузка или старый запрос, дождись состояния через wait_for_screen и посмотри снова, не отправляй тот же поиск вслепую. При выборе N-го результата считай реальные карточки на экране и проверь текущий фокус перед select, затем название в плеере; число отправленных стрелок не доказывает правильный выбор.
