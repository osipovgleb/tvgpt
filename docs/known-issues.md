# Известные проблемы · 0.1.1-preview

Экспериментальное превью,18 октября2026. Основной проверяемый телевизор — TCL Android12/API31, ARMv7. Это список подтверждённых ограничений и ещё не проверенных исправлений, а не обещание стабильной работы.

| Область | Что известно | Состояние / обходной путь |
| --- | --- | --- |
| Запуск после простоя на TCL | TCL Guard завершал процесс (`tguard-kill`), после чего прошивка запрещала его перезапуск и вызов кнопкой. Роль ассистента оставалась назначенной. | В текущей сборке настройка замены помощника разрешает поддерживаемые OEM `APP_AUTO_START` / `APP_ASSOC_START` только для TV GPT. Добавляется проверенное исключение пакета в текущий список очистки TGuard; при старте процесса оно восстанавливается через уже настроенный локальный пульт. Это не постоянное изменение конфигурации прошивки. Немедленный вызов после изменения проверен. Длительный простой и перезагрузка ещё не подтверждены. При повторе открыть TV GPT и повторить настройку замены помощника. |
| Первый вызов после обновления | В одной проверке окно закрылось до подключения; следующий вызов подключился. Ранее после перепривязки был BadTokenException окна доступности. | Устаревшая служба очищается при unbind, ошибочный токен переводит показ в существующее системное окно вместо падения. Причина отдельного раннего закрытия пока не установлена; повторный запуск может помочь. |
| Завершение разговора | Live иногда подтверждает действие словами без делегирования; закрытие голосом остаётся нестабильным. | Новые исправления запрещают самоотмену текущего поручения и не дают старым результатам принудительно перебивать новую реплику. Повторное голосовое закрытие требует проверки. Кнопка ассистента закрывает текущий разговор локально. |
| Действия вместо обещаний | Исполнитель мог отменить собственную задачу, а независимые задачи — попеременно менять один экран. | Самоотмена отклоняется; экран принадлежит одному поручению до его завершения. Проверено host-тестами; один переход на главный экран из живой речи прошёл с проверкой состояния. Это не подтверждает все приложения и команды. |
| Fast | Отправленный `priority` не всегда принимается: сервер отвечает `default`. | Интерфейс различает запрошенный и фактический режим. Гарантировать ускорение по подписке пока нельзя; доступность определяется сервером. |
| YouTube и похожие интерфейсы | Cobalt может возвращать дерево без полезных подписей. Принятый `commitText` не доказывает ввод поискового запроса. | Используются scoped search, доступные элементы и команды пульта, при необходимости изображение. Поиск и выбор результата всё ещё могут ошибаться; нет универсальной проверки содержимого для всех приложений. |
| Микрофон и фоновый вызов | Google Katniss на целевом TCL конкурирует за микрофон. Локальная фраза вызова держит микрофон активным; Android показывает зелёную точку. | Настройка замены помощника проверяет роль и отключает голосовой пакет Google. Фоновую фразу можно выключить в настройках. Работа микрофона на других прошивках не подтверждена. |
| Приглушение | Система сама определяет степень AudioFocus ducking; точные10% для других приложений недоступны с текущими правами. | Общая громкость MUSIC не меняется, чтобы не приглушать самого помощника. Некоторые приложения могут иначе обрабатывать фокус. |
| Превью голосов | Проприетарные голосовые образцы не включены в публичный APK. | Личная сборка может добавить их из внешней приватной папки. Их наличие не означает доступность соответствующего голоса/Live-модели по подписке. |
| Протокол, заставка, расписания | Используется экспериментальный протокол подписки. Автозапуск заставки, standby, все расписания и длительная стабильность не проверены полностью на устройстве. | Host-тесты проверяют логику, но не доказывают слышимость уведомлений, стабильность сети или поведение прошивки. |

Не устанавливайте обновления через incremental ADB на проверенном TCL: системный DataLoader уже удалял пакет и данные после формального сообщения Success. Используйте `adb install --no-incremental -r …`, без удаления приложения и очистки данных.

Для отчёта об ошибке укажите версию, модель/Android телевизора, способ вызова и последовательность действий. Не публикуйте токены, данные аккаунта, базы разговоров или запись микрофона. Текущие задачи можно исследовать через локальный permission-protected `dumpsys activity service local.tvgpt.assistant/.AssistantService`; этот вывод может содержать текст разговора, поэтому его нужно обезличить перед публикацией.
